# Fihrist — tanıtım sitesi

[fihrist](https://github.com/yerdekalmazer/fihrist) uygulamasının tanıtım
sayfası ve App Store'un zorunlu tuttuğu gizlilik/destek sayfaları.

GitHub Pages ile yayınlanır:

| Sayfa | Adres |
|---|---|
| Tanıtım | `/` |
| Gizlilik politikası | `/gizlilik.html` |
| Destek | `/destek.html` |

Bağımlılık yok: tek dosya HTML, satır içi CSS, karanlık mod desteği.
Görseller `gorseller/` altında, 720 piksel genişliğe indirilmiş.
